## 1. 系统概述

### 1.1 核心策略

本系统基于 **"下游无人问津"（Downstream Undiscovered）** 策略构建评分模型：

- **上游已热**：投中网文章覆盖的行业被视为"已热"（媒体已关注）
- **下游未动**：这些热门行业的下游/相关行业中，尚未被市场充分关注的个股
- **接力逻辑**：资金从热门行业溢出到相关受益行业，形成"接续上涨"
- **推特验证**：利用 Twitter 社交数据验证行业热度真实性及个股舆论真空状态

### 1.2 两条评分路径

| 路径 | 函数 | 持有期 | 满分 |
|------|------|--------|------|
| 短线 | `evaluate_short_term()` | 1-5 天 | 100 |
| 中线 | `evaluate_mid_term()` | 1-4 周 | 100 |

### 1.3 数据源

| 数据 | 来源 | 用途 |
|------|------|------|
| 投中网文章 | `fetch_chinaventure.py` | 提取当日热门行业 |
| 供应链知识库 | `data/supply_chain.csv` | 行业→股票映射 |
| 行情数据 | `fetch_market_eastmoney.py` | MA/RSI/MACD/成交量等技术指标 |
| Twitter/X 数据 | `fetch_x_recent.py` | 社交热度验证、舆论真空检测 |
| 个股别名 | `data/stock_aliases.csv` | 股票名称/代码匹配 |

## 2. 短线评分模型（持有1-5天）

> **函数**：[`evaluate_short_term(social, market_row, stock_info, ...)`](../src/supply_chain_report.py:286)
>
> **目标**：寻找"下游无人问津"的短线交易机会

### 2.1 评分维度总览

| # | 维度 | 代码权重 | 描述 |
|---|------|----------|------|
| 1 | 供应链深度 | 0-25 | 纯下游受益=高分，直击热门行业=低分（惩罚过热） |
| 2 | 价格阶段（早期进场） | 0-25 | 判断股价是否处于 20 日区间底部，还有上涨空间 |
| 3 | 成交量苏醒 | 0-15 | 量比 0.8~1.5x=健康，>2.0x=过热 |
| 4 | RSI 甜区 | 0-10 | 30~60=理想区间 |
| 5 | MA 支撑 | 0-10 | 股价在 MA20 附近为佳 |
| 6 | 趋势质量 | 0-15 | MA5>MA20=上升趋势，MACD 为正确认 |
| 7 | 舆论接力信号 | 0-10 | 推特验证的接力逻辑 |
| **总分** | | **100** | |

### 2.2 维度详解

#### ① 供应链深度（0-25）

根据个股所属行业与当日热门行业的关系打分：

```
场景矩阵：
┌──────────────────┬──────────────────┬──────────────────┐
│ 条件             │ 得分             │ 说明             │
├──────────────────┼──────────────────┼──────────────────┤
│ 纯下游受益       │ 25               │ 🟢 最佳——无人问津的下游 │
│ (related_match && !direct_match)    │                  │
├──────────────────┼──────────────────┼──────────────────┤
│ 直击热门行业     │ 5                │ 🔴 惩罚——已过热     │
│ (direct_match && !related_match)    │                  │
├──────────────────┼──────────────────┼──────────────────┤
│ 两者皆有+接力逻辑 │ 25               │ 🟢 接力逻辑不扣分   │
│ (direct+related+is_lagging)         │                  │
├──────────────────┼──────────────────┼──────────────────┤
│ 两者皆有-无接力   │ 15               │ 🟡 中等评级         │
│ (direct+related-!is_lagging)        │                  │
├──────────────────┼──────────────────┼──────────────────┤
│ 无匹配           │ 0                │                  │
└──────────────────┴──────────────────┴──────────────────┘
```

**接力逻辑判断**：检查个股行业是否在 [`LAGGING_BENEFITS`](#8-接力受益矩阵) 中作为某个热门行业的受益方。

#### ② 价格阶段 / 早期进场（0-25）

> **函数**：[`calc_price_stage_score(market_row, max_score=25)`](../src/supply_chain_report.py:247)

核心公式：
```
range_pos = (close - support) / (resistance - support)   // 0.0(底部) ~ 1.0(顶部)
room_pct  = (resistance - close) / close * 100            // 距阻力位的空间%

position_factor = 1.0 - range_pos            // 越低越好(在底部)
room_factor     = min(1.0, room_pct / 8.0)   // 8%+空间=满因子

score = max_score × position_factor × room_factor
```

- 已突破阻力位（close > resistance）→ **0分**（已涨完，追高不宜）
- 价格在区间底部 + 距阻力空间大 → 高分

#### ③ 成交量苏醒（0-15）

```
量比 = 当日成交量 / 5日均量

0.8 ≤ 量比 ≤ 1.5  → 15分  🟢 健康苏醒
0.5 ≤ 量比 < 0.8  →  8分  🟡 量能不足
1.5 < 量比 ≤ 2.0  →  8分  🟡 略放量
量比 > 2.0        →  3分  🔴 过热放量
量比 < 0.5        →  0分  🔴 极度缩量
```

> 短线交易量比 0.8~1.5x 是"无人问津→刚苏醒"的理想区间。

#### ④ RSI 甜区（0-10）

```
30 ≤ RSI ≤ 60   → 10分  🟢 理想区间（未过热）
60 < RSI ≤ 70   →  7分  🟡 中性偏高
25 ≤ RSI < 30   →  7分  🟡 中性偏低
70 < RSI ≤ 80   →  3分  🔴 接近过热
20 ≤ RSI < 25   →  3分  🔴 超卖但不严重
RSI > 80        →  0分  🔴 严重过热
RSI < 20        →  0分  🔴 严重超卖
```

#### ⑤ MA 支撑（0-10）

```
距MA20百分比 = (close - ma20) / ma20 × 100

-2% ~ +3%   → 10分  🟢 紧贴MA20
-5% ~ -2%   →  8分  🟡 略低于MA20
+3% ~ +8%   →  5分  🟡 略高于MA20
> +8%       →  0分  🔴 偏离过远
< -5%       →  3分  🔴 跌破MA20
```

> MA20 被视为短期生命线，短线交易应在 MA20 附近介入。

#### ⑥ 趋势质量（0-15）

```
MA5 > MA20 (上升趋势)  →  +10分
MACD 柱为正            →   +5分
─────────────────────────────
MA5 < MA20 (下跌趋势)  →  3分 (MACD > -0.1) 或 0分 (MACD 深负)
```

#### ⑦ 舆论接力信号（0-10）

见独立章节 [舆论接力信号](#5-舆论接力信号)。

### 2.3 短线代码执行流程

```
evaluate_short_term():
  ├─ ① supply_chain_depth     (0-25)
  ├─ ② price_stage_score     (0-25)  ← calc_price_stage_score()
  ├─ ③ volume_awakening      (0-15)
  ├─ ④ rsi_sweet_spot        (0-10)
  ├─ ⑤ ma_proximity          (0-10)
  ├─ ⑥ trend_quality         (0-15)
  ├─ ⑦ sentiment_relay       (0-10)  ← calc_sentiment_relay_score()
  └─ ⚡ global_trend_cap      (上限30/50)
```

## 3. 中线评分模型（持有1-4周）

> **函数**：[`evaluate_mid_term(social, market_row, stock_info, ...)`](../src/supply_chain_report.py:457)

### 3.1 评分维度总览

| # | 维度 | 权重 | 描述 |
|---|------|------|------|
| 1 | 行业顺风 | 0-25 | 同短线供应链深度逻辑 |
| 2 | 价格阶段 | 0-25 | 同短线，判断早期进场位置 |
| 3 | MA 支撑 | 0-20 | 价格在 MA20/MA60 支撑位附近 |
| 4 | MACD 转向 | 0-15 | MACD 柱刚转正或接近零轴 |
| 5 | 成交量筑底 | 0-15 | 温和放量筑底 |
| 6 | 舆论接力信号 | 0-10 | 同短线 |

**中线与短线的关键差异**：

| 维度 | 短线 | 中线 |
|------|------|------|
| MA 支撑权重 | 10分（MA20） | 20分（MA20+MA60） |
| 成交量 | 0.8~1.5x 苏醒 | 0.8~1.8x 筑底 |
| MACD | 仅是趋势确认的 5 分 | 独立维度 15 分 |
| 趋势质量 | 独立 15 分 | — |
| RSI | 独立 10 分 | — |

### 3.2 MA 支撑（中线 0-20）

```
-2% ≤ 距MA20 ≤ +5%  → 20分  🟢 在MA20附近筑底
-2% ≤ 距MA60 ≤ +5%  → 15分  🟡 在MA60附近获得支撑
+5% < 距MA20 ≤ +10% → 10分  🟡 略高于MA20
> +10%              →  0分  🔴 偏离过远
其他                →  5分
```

### 3.3 MACD 转向（中线 0-15）

```
0 < MACD柱 < 1     → 15分  🟢 刚转正（最佳进场点）
MACD柱 ≥ 1         → 10分  🟡 已转正一段时间
-1 ≤ MACD柱 ≤ 0    →  8分  🟡 接近零轴
-2 ≤ MACD柱 < -1   →  3分  🔴 仍在负值
MACD柱 < -2        →  0分  🔴 深负
```

### 3.4 成交量筑底（中线 0-15）

```
0.8 ≤ 量比 ≤ 1.8  → 15分  🟢 温和放量筑底
0.5 ≤ 量比 < 0.8  →  8分  🟡 缩量筑底
1.8 < 量比 ≤ 3.0  →  6分  🟡 放量
量比 > 3.0        →  3分  🔴 异常放量
量比 < 0.5        →  0分
```

## 4. 价格阶段评分

> **函数**：[`calc_price_stage_score(market_row, max_score)`](../src/supply_chain_report.py:247)

这是一个被 **短线和中线共享** 的核心函数，用于判断个股是否处于"早期进场"位置。

### 4.1 输入参数

| 参数 | 来源 | 说明 |
|------|------|------|
| `close` | 行情数据 | 当日收盘价 |
| `support` | 行情数据 | 20 日区间支撑位（最低价） |
| `resistance` | 行情数据 | 20 日区间阻力位（最高价） |

### 4.2 计算逻辑

```
1. range_pos = (close - support) / (resistance - support)
   → 0.0 = 在区间底部（好）
   → 1.0 = 在区间顶部（不好）

2. room_pct = (resistance - close) / close × 100
   → 距阻力位的上涨空间百分比

3. 如果 close > resistance（已突破）：
   → 返回 0（已涨完，不能早期进场）

4. position_factor = 1.0 - range_pos
   → 0.0(顶部) ~ 1.0(底部)

5. room_factor = min(1.0, room_pct / 8.0)
   → 8%+空间 = 1.0 满因子

6. score = max_score × position_factor × room_factor
```

### 4.3 判定逻辑图解

```
价格区间                  支撑位(S)            阻力位(R)
  ├─────────────────────────┼────────────────────┼──────►
  超跌区                   底部进场区            过热区
  (room > 8%)              (room 3-8%)          (已突破=0分)
  position_factor≈1.0      position_factor 中等
  room_factor=1.0          room_factor 0.4-1.0
```

## 5. 舆论接力信号

> **函数**：[`calc_sentiment_relay_score(price_stage_score, rsi_val, stock_inds, industries_found, social, all_social_stats, industry_stock_map)`](../src/supply_chain_report.py:87)

### 5.1 核心洞察

```
"中际旭创火了 + 东山精密无人问津" = 最佳接力机会
        ↑                           ↑
    行业推特验证                   个股舆论真空
```

### 5.2 公式

```
sentiment_relay = min(10, base × confirm × vacuum)
```

### 5.3 三步计算

#### Step 1: Base（基于价格空间）

| `price_stage_score` | base | 说明 |
|---------------------|------|------|
| > 15 | 4 | 深蹲底部，大量空间 |
| > 10 | 3 | 中等空间 |
| > 0 | 2 | 少量空间 |
| ≤ 0 | 0 | 无空间，不接力 |

#### Step 2: confirm（行业点火验证）

> 通过 Twitter 数据验证热门行业是否真实有社交热度。

| 行业 Twitter 提及数 | confirm | 说明 |
|---------------------|---------|------|
| ≥ 5 | 1.5x | 🔥 推特确认行业火爆 |
| 2-4 | 1.2x | 有一定讨论度 |
| 0（有推特数据） | 0.8x | 推特存在但行业无人讨论 |
| 无推特数据 | 1.0x | 退回到纯产业逻辑 |

#### Step 3: vacuum（个股舆论真空）

> 检查个股自身的 Twitter 提及量——"无人问津"程度。

| 个股提及数 | vacuum | 说明 |
|-----------|--------|------|
| 0 | 1.5x | 🟢 真正无人问津，最佳接力时机 |
| 1-2 | 1.2x | 🟡 轻度讨论 |
| 3-5 | 0.8x | 🟡 已被一定发现 |
| > 5 | 0.5x | 🔴 话题过热，不接力 |

### 5.4 跳过条件

```
if not industries_found → return 0       // 没有热门行业
if price_stage_score ≤ 0 → return 0      // 没有价格空间
if RSI ≥ 60 → return 0                   // RSI 过热
```

## 6. 价格计算器

### 6.1 短线价格计算

> **函数**：[`calc_short_term_prices(market_row, social)`](../src/supply_chain_report.py:608)

| 项目 | 计算方式 |
|------|----------|
| 买入价 | `close × 0.99`（小幅挂低，等待回调） |
| 目标涨幅 | 基准 3.0% + 情绪加成（最高 +2%）+ 成交量加成（最高 +1%）+ 低提及加成（最高 +1.5%），**上限 8%** |
| 目标价 | `buy_price × (1 + target_pct%)` |
| 止损 | `buy_price × 0.97`（-3%） |

**目标涨幅加成规则**：
```
avg_sentiment > 0 → +min(sentiment, 4.0) × 0.5    // 情绪越好目标越高
0.8 ≤ 量比 ≤ 1.5 → +1.0%                          // 健康放量
mention ≤ 2       → +1.5%                          // 无人问津加成
mention ≤ 5       → +0.8%
```

### 6.2 中线价格计算

> **函数**：[`calc_mid_term_prices(market_row, social)`](../src/supply_chain_report.py:655)

| 项目 | 计算方式 |
|------|----------|
| 买入价 | `min(close, ma20)`（在 MA20 附近介入） |
| 目标涨幅 | 基准 8.0% + 均线结构加成（最高 +3%）+ 情绪加成，**上限 20%** |
| 目标价 | `buy_price × (1 + target_pct%)` |
| 止损 | `buy_price × 0.95`（-5%） |

## 8. 接力受益矩阵

> **定义位置**：[`LAGGING_BENEFITS`](../src/supply_chain_report.py:57)

定义当行业 A 热门时，哪些行业 B 的股票应该获得"接力"加分。这是 **"舆论接力信号"** 的核心产业逻辑基础。

| 热门行业(A) | 接力受益行业(B) |
|-------------|----------------|
| 存储芯片 | 先进封装、半导体设备、半导体材料 |
| AI 芯片 | 先进封装、半导体设备、半导体材料 |
| 人工智能 | AI 芯片、存储芯片、机器人 |
| 半导体 | 先进封装、半导体设备、半导体材料 |
| 新能源车 | 锂电池、功率半导体、机器人 |
| 新能源 | 光伏储能、锂电池、功率半导体 |
| 光伏储能 | 功率半导体 |
| 消费电子 | 先进封装、存储芯片、半导体设备 |

### 8.1 逻辑示例

```
今日热门（投中网文章覆盖）：
  → AI 芯片 (多篇文章覆盖，行业已热)

根据 LAGGING_BENEFITS：
  → 先进封装、半导体设备、半导体材料 = 接力受益方

评分行为：
  1. 先进封装行业的股票 → 获得接力加分（如果价格尚未拉升）
  2. 但如果该股票 RSI ≥ 60 或价格已突破阻力 → 不接力
  3. 如果 Twitter 验证 AI 芯片确实有社交讨论 → confirm 1.5x
  4. 如果该股票在 Twitter 上无人提及 → vacuum 1.5x → 高分接力信号
```

## 9. 全局约束规则

### 9.1 趋势上限

> **短线**：[L444-452](../src/supply_chain_report.py:444) / **中线**：[L595-600](../src/supply_chain_report.py:595)

| 条件 | 解释 | 总分上限 |
|------|------|----------|
| `close < MA5 < MA20` | 强下跌趋势（收盘<5日均线<20日均线） | **30** |
| `MA5 < MA20` | 弱下跌趋势（5日均线<20日均线） | **50** |
| `MA5 > MA20` | 上升趋势 | 无上限 |

### 9.2 股票过滤规则

| 过滤条件 | 实现方式 | 说明 |
|----------|----------|------|
| 科创板排除 | `--exclude-prefixes "688"` | 688xxx 代码 |
| 创业板排除 | `--exclude-prefixes "300"` | 300xxx 代码 |

### 9.3 候选排序规则

```
最终排名 = 短线得分 降序（短线推荐候选）
最终排名 = 中线得分 降序（中线推荐候选）
```
